## Skill Loading

TanStack ships skills inside its packages. Before a substantial change, list them from this folder with
`bunx @tanstack/intent@latest list` and load the matching one with `bunx @tanstack/intent@latest load <package>#<skill>`
(e.g. `@tanstack/solid-start#solid-start`, `@tanstack/start-client-core#start-core/deployment`).
